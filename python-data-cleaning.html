🧹 Python Data Cleaning

Clean and Prepare Data for Analysis

📘 What is Data Cleaning?

Data cleaning means finding and correcting missing, duplicate, incorrect or inconsistent data.

❓ Handling Missing Values

df.isnull().sum()

This checks the number of missing values in each column.

🗑️ Remove Missing Rows

df.dropna()

dropna() removes rows containing missing values.

➕ Fill Missing Values

df.fillna(0)

fillna() can replace missing values with a specified value.

♻️ Remove Duplicate Rows

df.drop_duplicates()

This removes duplicate records from the DataFrame.

🔤 Clean Text Data

df["Name"] = df["Name"].str.strip()

strip() removes unnecessary spaces from text.

🔄 Change Data Type

df["Age"] = df["Age"].astype(int)

astype() can convert a column to another data type.

🔍 Check Dataset

df.info()
df.describe()
df.head()

These commands help understand the dataset before analysis.

⭐ Why Data Cleaning is Important?

• Improves data quality

• Removes duplicate records

• Handles missing values

• Makes analysis more accurate

• Important skill for Data Analysts
