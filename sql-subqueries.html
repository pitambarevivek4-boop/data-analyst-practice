🔁 SQL Subqueries

Practice Subqueries for Data Analyst

📘 What is a Subquery?

A subquery is a query written inside another SQL query. It is also called a nested query.

1️⃣ Greater Than Average

Find employees whose salary is greater than the average salary.

SELECT * FROM Employees
WHERE salary > (SELECT AVG(salary) FROM Employees);

2️⃣ Maximum Salary

Find employees who have the maximum salary.

SELECT * FROM Employees
WHERE salary = (SELECT MAX(salary) FROM Employees);

3️⃣ Minimum Salary

Find employees who have the minimum salary.

SELECT * FROM Employees
WHERE salary = (SELECT MIN(salary) FROM Employees);

4️⃣ Greater Than Employee ID 5

Find vehicles whose price is greater than the price of vehicle ID 5.

SELECT * FROM Vehicles
WHERE price > (
  SELECT price FROM Vehicles WHERE vehicle_id = 5
);

5️⃣ Same Vehicle Type

Find vehicles that belong to the same vehicle type as vehicle ID 5.

SELECT * FROM Vehicles
WHERE vehicle_type = (
  SELECT vehicle_type FROM Vehicles WHERE vehicle_id = 5
);

6️⃣ Above Branch Average Price

Find vehicles whose price is greater than the average price of their branch.

SELECT * FROM Vehicles v
WHERE price > (
  SELECT AVG(price)
  FROM Vehicles
  WHERE branch = v.branch
);

Find all vehicles whose price is greater than the average price of all vehicles.
