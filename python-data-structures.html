📦 Python Data Structures

Lists, Tuples, Sets & Dictionaries

📋 List

List is an ordered and changeable collection. It allows duplicate values.

fruits = ["Apple", "Banana", "Mango"]

Useful methods:

fruits.append("Orange")
fruits.remove("Banana")

🔒 Tuple

Tuple is an ordered collection that cannot be changed after creation.

colors = ("Red", "Blue", "Green")

🔢 Set

Set stores unique values and does not allow duplicates.

numbers = {1, 2, 3, 3}

Output will contain only unique values.

🗂️ Dictionary

Dictionary stores data in key-value pairs.

student = {"name": "Vivek", "age": 29} print(student["name"])

📌 List Indexing

fruits = ["Apple", "Banana", "Mango"]
print(fruits[0])

Output: Apple

🧠 Important Difference

List: Ordered + Changeable

Tuple: Ordered + Not Changeable

Set: Unique Values

Dictionary: Key-Value Pairs

📝 Practice Question

Which Python data structure stores data in key-value pairs?

Answer: Dictionary
