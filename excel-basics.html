📘 Excel Basics

Learn Excel from Beginner Level

1. What is Excel?

Microsoft Excel is a spreadsheet software used to store, organize, calculate and analyze data.

2. Workbook & Worksheet

A Workbook is an Excel file. A Worksheet is a sheet inside the workbook where we enter and work with data.

3. Rows & Columns

Rows are numbered 1, 2, 3... and Columns are named A, B, C...

4. Cell

A cell is the intersection of a row and a column. Example: A1, B2, C5.

5. Basic Formulas

SUM, AVERAGE, COUNT, MIN and MAX are commonly used Excel functions.

6. Sorting & Filtering

Sorting arranges data in an order. Filtering displays only the data that matches selected conditions.

Q1. What is the intersection of a row and column called?
