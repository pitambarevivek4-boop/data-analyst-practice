📘 SQL Basics

Learn SQL from Beginner Level

1. What is SQL?

SQL stands for Structured Query Language. It is used to store, retrieve, manage and analyze data in databases.

2. What is a Database?

A database is an organized collection of data that can be stored, managed and accessed easily.

3. What is a Table?

A table stores data in rows and columns.

4. Rows and Columns

A row represents one record, while a column represents a specific field or attribute.

5. SELECT Statement

The SELECT statement is used to retrieve data from a table.

SELECT * FROM Students;

6. WHERE Clause

WHERE is used to filter records based on a condition.

SELECT * FROM Students WHERE age > 20;

7. ORDER BY

ORDER BY is used to sort data in ascending or descending order.

SELECT * FROM Students ORDER BY age DESC;

8. DISTINCT

DISTINCT is used to return unique values.

SELECT DISTINCT city FROM Students;

9. NULL

NULL represents a missing or unknown value in a database.

SELECT * FROM Students WHERE phone IS NULL;

10. Primary Key

A Primary Key uniquely identifies each record in a table.
