📝 SQL Practice Questions

Data Analyst SQL Practice

Q1. Find all students from Mumbai.

SELECT * FROM Students WHERE city = 'Mumbai';

Q2. Find students whose age is greater than 20.

SELECT * FROM Students WHERE age > 20;

Q3. Display students in descending order of age.

SELECT * FROM Students ORDER BY age DESC;

Q4. Find the total number of students.

SELECT COUNT(*) FROM Students;

Q5. Find the average age of students.

SELECT AVG(age) FROM Students;

Q6. Find the oldest student.

SELECT MAX(age) FROM Students;

Q7. Find students whose phone number is NULL.

SELECT * FROM Students WHERE phone IS NULL;

Q8. Display unique cities.

SELECT DISTINCT city FROM Students;

Q9. Find cities having more than 2 students.

SELECT city, COUNT(*) FROM Students
GROUP BY city
HAVING COUNT(*) > 2;

Q10. Find employees earning more than the average salary.

SELECT * FROM Employees
WHERE salary > (SELECT AVG(salary) FROM Employees);
