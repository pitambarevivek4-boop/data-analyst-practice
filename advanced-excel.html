📊 Advanced Excel

Data Analyst Excel Skills

📌 Pivot Tables

Pivot Table is used to summarize and analyze large datasets.

Example: Calculate total sales by product or city.

📈 Charts

Charts help us visualize data and understand trends.

Common charts: Column Chart, Bar Chart, Line Chart and Pie Chart.

🎨 Conditional Formatting

It automatically formats cells based on conditions.

Example: Highlight sales greater than 50000.

🧹 Data Cleaning

Data cleaning means removing errors, duplicates and unwanted spaces.

Useful tools: Remove Duplicates, TRIM, Find & Replace.

✅ Data Validation

Data Validation controls what users can enter into a cell.

Example: Create a dropdown list for Male/Female.

📋 Excel Tables

Excel Tables make data easier to manage, filter and analyze.

Shortcut: Ctrl + T

💡 Analyst Practice

Question: Which Excel feature is best for summarizing thousands of sales records?

A) WordArt   B) Pivot Table   C) Paint   D) Header

Answer: B) Pivot Table
