🎤 Power BI Interview

Data Analyst Interview Preparation

Q1. What is Power BI?

Power BI is a Microsoft Business Intelligence tool used to connect, transform, analyze and visualize data.

Q2. What is Power BI Desktop?

Power BI Desktop is the application used to create reports, data models and visualizations.

Q3. What is Power Query?

Power Query is used to import, clean and transform data before analysis.

Q4. What is DAX?

DAX stands for Data Analysis Expressions. It is used to create calculations, measures and calculated columns.

Q5. What is a Measure?

A measure is a DAX calculation that is evaluated dynamically according to the report context.

Q6. What is a Calculated Column?

A calculated column is a new column created using a DAX formula.

Q7. What is Data Modeling?

Data modeling means creating tables and relationships so that data can be analyzed correctly.

Q8. What is a Star Schema?

A Star Schema contains a central fact table connected to multiple dimension tables.

Q9. What is a Slicer?

A Slicer is an interactive visual used to filter report data.

Q10. What is a Dashboard?

A dashboard presents important business information using visualizations and key metrics.

Q11. What is a Report?

A report is a collection of pages containing visualizations, filters and data analysis.

Q12. What is CALCULATE() in DAX?

CALCULATE() evaluates an expression after modifying the filter context.

Q13. What is a Fact Table?

A fact table contains measurable business data such as sales, quantity and profit.

Q14. What is a Dimension Table?

A dimension table contains descriptive information such as customers, products, categories and dates.

Q15. What is a Relationship in Power BI?

A relationship connects two tables using related columns, such as Customer ID.

Q16. What is One-to-Many Relationship?

It means one record in one table can be related to many records in another table.

Q17. What is Drill Down?

Drill Down allows users to move from a higher-level summary to more detailed information.

Q18. What is a Filter?

A filter limits the data displayed in a Power BI report or visual.

Q19. What is a KPI?

KPI stands for Key Performance Indicator. It is used to track important business performance metrics.

Q20. Why is Power BI important for a Data Analyst?

Power BI helps Data Analysts transform data, create interactive reports and communicate business insights through visualizations.
