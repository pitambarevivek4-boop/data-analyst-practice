📊 Power BI Visualizations

Learn Charts, Graphs & Interactive Reports

1. What are Visualizations?

Visualizations represent data in a graphical format so that users can understand trends and patterns easily.

2. Bar Chart

Bar charts are useful for comparing values between different categories.

3. Column Chart

Column charts display values using vertical bars and are useful for category comparisons.

4. Line Chart

Line charts are commonly used to show trends over time.

5. Pie Chart

Pie charts show how different categories contribute to a total.

6. Card

A Card displays an important single number such as Total Sales, Profit or Customer Count.

7. Table

A Table displays detailed data in rows and columns.

8. Slicer

A Slicer allows users to filter report data interactively.

9. Dashboard

A Power BI dashboard can present important business information using multiple visuals.

📝 Practice Question

Which visual is commonly used to show a trend over time?

✅ Answer: Line Chart
