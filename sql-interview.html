🎤 SQL Interview

Data Analyst Interview Preparation

Q1. What is SQL?

SQL stands for Structured Query Language. It is used to store, retrieve, manipulate and analyze data in relational databases.

Q2. What is a Database?

A database is an organized collection of data that can be stored, managed and accessed efficiently.

Q3. What is a Primary Key?

A Primary Key uniquely identifies each record in a table. It cannot contain duplicate or NULL values.

Q4. What is a Foreign Key?

A Foreign Key is a column that creates a relationship between two tables by referring to a key in another table.

Q5. Difference between WHERE and HAVING?

WHERE filters rows before grouping. HAVING filters grouped results after GROUP BY.

Q6. What is GROUP BY?

GROUP BY groups rows having the same values and is commonly used with aggregate functions.

Q7. What is a JOIN?

JOIN is used to combine data from two or more tables using related columns.

Q8. What is an INNER JOIN?

INNER JOIN returns only the records that have matching values in both tables.

Q9. What is a LEFT JOIN?

LEFT JOIN returns all records from the left table and matching records from the right table.

Q10. What is a Subquery?

A subquery is a query written inside another SQL query.

Q11. Difference between DELETE, DROP and TRUNCATE?

DELETE removes selected rows, TRUNCATE removes all rows from a table, and DROP removes the table itself.

Q12. What is NULL?

NULL represents a missing or unknown value. It is checked using IS NULL or IS NOT NULL.

Q13. What is DISTINCT?

DISTINCT removes duplicate values from the result.

Q14. What is ORDER BY?

ORDER BY sorts the result in ascending or descending order.

Q15. What are Aggregate Functions?

Aggregate functions perform calculations on multiple rows. Examples: COUNT(), SUM(), AVG(), MAX() and MIN().

Q16. What is a VIEW?

A VIEW is a virtual table based on the result of an SQL query.

Q17. What is a SELF JOIN?

SELF JOIN joins a table with itself.

Q18. What is UNION?

UNION combines the results of two compatible SELECT queries and removes duplicate rows.

Q19. What is an Index?

An Index helps the database find and retrieve data faster.

Q20. Why is SQL important for a Data Analyst?

SQL helps Data Analysts retrieve, filter, join, aggregate and analyze data stored in databases.
