🐼 NumPy & Pandas

Python Libraries for Data Analysis

🔢 What is NumPy?

NumPy is a Python library used for numerical calculations and working with arrays.

import numpy as np

numbers = np.array([10, 20, 30, 40])

📊 NumPy Array

import numpy as np

numbers = np.array([10, 20, 30])
print(numbers)

NumPy arrays are useful for numerical data and calculations.

🐼 What is Pandas?

Pandas is a Python library used for data manipulation and analysis.

import pandas as pd

📋 Pandas DataFrame

A DataFrame is a table-like structure with rows and columns.

import pandas as pd

data = {"Name": ["Amit", "Rahul"],
"Age": [25, 28]}

df = pd.DataFrame(data)
print(df)

📥 Reading CSV File

Pandas can read CSV files for data analysis.

df = pd.read_csv("sales.csv")

👀 View Data

df.head()

head() displays the first few rows of the DataFrame.

🧹 Basic Data Analysis

df.info()
df.describe()
df.shape

These functions help understand the dataset.
