📘 Python Basics

Learn Python from Beginner Level

🐍 What is Python?

Python is a popular programming language used for Data Analysis, Automation, Web Development, Artificial Intelligence and Machine Learning.

📝 Python Print

The print() function is used to display output.

print("Hello World")

📦 Variables

Variables are used to store data values.

name = "Vivek"
age = 29
salary = 25000

🔢 Data Types

Common Python data types include:

  • String
  • Integer
  • Float
  • Boolean
  • List
  • Tuple
  • Dictionary

➕ Basic Operators

a = 10
b = 5

print(a + b)
print(a - b)
print(a * b)
print(a / b)

🔤 Strings

Strings are used to store text.

name = "Data Analyst"
print(name)

📋 Comments

Comments are used to explain code and are ignored by Python.

# This is a comment
print("Hello")

🎯 Practice Question

Question: Which function is used to display output in Python?
