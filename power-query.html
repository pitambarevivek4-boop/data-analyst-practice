🔄 Power Query

Data Cleaning & Transformation

1. What is Power Query?

Power Query is a data preparation tool used to import, clean and transform data before analysis.

2. Import Data

Power Query can import data from Excel, CSV, databases and many other sources.

3. Remove Duplicates

Remove duplicate rows to keep the dataset clean and accurate.

4. Remove Empty Rows

Blank or unnecessary rows can be removed during data cleaning.

5. Change Data Type

Columns can be changed to Text, Whole Number, Decimal Number, Date and other data types.

6. Filter Rows

Filtering allows you to keep only the rows required for analysis.

7. Split Columns

A column can be split into multiple columns using a delimiter such as comma, space or hyphen.

8. Merge Columns

Two or more columns can be combined into a single column.

9. Replace Values

Power Query allows you to find and replace incorrect or unwanted values.

10. Close & Apply

After completing transformations, use Close & Apply to load the prepared data into Power BI.
