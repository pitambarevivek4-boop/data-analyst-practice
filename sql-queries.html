🔎 SQL Queries

Data Analyst Query Practice

1️⃣ WHERE

Used to filter records based on a condition.

SELECT * FROM Students WHERE age > 20;

2️⃣ ORDER BY

Used to sort data in ascending or descending order.

SELECT * FROM Students ORDER BY age DESC;

3️⃣ DISTINCT

Used to display unique values.

SELECT DISTINCT city FROM Students;

4️⃣ GROUP BY

Used to group rows having the same values.

SELECT city, COUNT(*) FROM Students GROUP BY city;

5️⃣ HAVING

Used to filter grouped results.

SELECT city, COUNT(*) FROM Students GROUP BY city HAVING COUNT(*) > 2;

6️⃣ LIMIT

Used to restrict the number of records returned.

SELECT * FROM Students LIMIT 5;

7️⃣ AND

Used when multiple conditions must be true.

SELECT * FROM Students WHERE age > 20 AND city = 'Mumbai';

8️⃣ OR

Used when at least one condition should be true.

SELECT * FROM Students WHERE city = 'Mumbai' OR city = 'Pune';

Which SQL clause is used to filter grouped data?
