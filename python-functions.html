⚙️ Python Functions

Learn Functions and Reusable Code

📘 What is a Function?

A function is a reusable block of code that performs a specific task.

def greet():
    print("Hello")

▶️ Calling a Function

def greet():
    print("Hello")

greet()

Calling greet() executes the function.

📥 Function Parameters

Parameters allow us to pass data into a function.

def greet(name):
    print("Hello", name)

greet("Vivek")

↩️ Return Statement

The return statement sends a result back from the function.

def add(a, b):
    return a + b

result = add(10, 20)
print(result)

Output: 30

🔢 Function with Multiple Parameters

def multiply(a, b):
    return a * b

print(multiply(5, 4))

Output: 20

⭐ Why Functions are Important?

• Reuse code

• Reduce repetition

• Make programs easier to understand

• Useful for Data Analysis projects
