🎤 Excel Interview Questions

Data Analyst Interview Preparation

Q1. What is Microsoft Excel?

Excel is a spreadsheet application used to store, organize, calculate and analyze data.

Q2. What is the difference between COUNT and COUNTA?

COUNT counts cells containing numbers, while COUNTA counts non-empty cells.

Q3. What is a Pivot Table?

A Pivot Table summarizes and analyzes large datasets quickly.

Q4. What is VLOOKUP?

VLOOKUP searches for a value in the first column of a table and returns a related value from another column.

Q5. What is the difference between VLOOKUP and HLOOKUP?

VLOOKUP searches vertically, while HLOOKUP searches horizontally.

Q6. What is Conditional Formatting?

It automatically formats cells based on specified conditions.

Q7. What is Data Validation?

Data Validation controls the type of data that can be entered into a cell.

Q8. How do you remove duplicate records in Excel?

Select the data and use Data → Remove Duplicates.

Q9. What is the IF function?

IF checks a condition and returns one value if the condition is TRUE and another if it is FALSE.

Q10. Which Excel skills are useful for a Data Analyst?

Formulas, Pivot Tables, Charts, Data Cleaning, Conditional Formatting, XLOOKUP/VLOOKUP and data analysis.
