📝 Power BI Practice Questions

Data Analyst Practice

Q1. What is Power BI?

A. Programming Language
B. Business Intelligence Tool
C. Operating System
D. Database

✅ Answer: B. Business Intelligence Tool

Q2. Which tool is used to clean and transform data?

A. Power Query
B. PowerPoint
C. Word
D. Notepad

✅ Answer: A. Power Query

Q3. What is DAX?

A. Database
B. Formula Language
C. Operating System
D. Browser

✅ Answer: B. Formula Language

Q4. Which DAX function calculates total?

A. AVG()
B. SUM()
C. MAX()
D. COUNT()

✅ Answer: B. SUM()

Q5. Which visual is useful for showing trends over time?

A. Line Chart
B. Card
C. Table
D. Slicer

✅ Answer: A. Line Chart

Q6. What is a Slicer?

A. Data filter
B. Database
C. Formula
D. Table

✅ Answer: A. Data filter

Q7. Which schema is commonly used in Power BI?

A. Star Schema
B. Circle Schema
C. Square Schema
D. Linear Schema

✅ Answer: A. Star Schema

Q8. Which DAX function modifies filter context?

A. SUM()
B. COUNT()
C. CALCULATE()
D. MIN()

✅ Answer: C. CALCULATE()

Q9. What does a Card visual show?

A. Single important value
B. Multiple tables
C. SQL query
D. Database structure

✅ Answer: A. Single important value

Q10. What is the purpose of Data Modeling?

A. Connect and organize tables
B. Write emails
C. Create documents
D. Edit photos

✅ Answer: A. Connect and organize tables
