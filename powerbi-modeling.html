🗂️ Power BI Data Modeling

Learn Tables, Relationships & Data Models

1. What is Data Modeling?

Data modeling means creating relationships between tables so that data can be analyzed correctly in Power BI.

2. Tables

A Power BI model can contain multiple tables such as Sales, Customers, Products and Date.

3. Relationships

Relationships connect tables using common columns such as Customer ID or Product ID.

4. One-to-Many Relationship

One record in one table can be related to many records in another table. This is a common relationship in Power BI.

5. Primary Key

A primary key uniquely identifies each record in a table.

6. Foreign Key

A foreign key is a column used to connect one table with another table.

7. Star Schema

Star schema contains a central fact table connected to multiple dimension tables.

8. Fact Table

A fact table usually contains measurable business data such as Sales Amount, Quantity and Profit.

9. Dimension Table

Dimension tables contain descriptive information such as Customer, Product, Category and Date.

📝 Practice Question

Which schema is commonly used to create an efficient Power BI data model?

✅ Answer: Star Schema
