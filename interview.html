Excel Interview Questions

1. What is VLOOKUP in Excel?

VLOOKUP is used to search for a value in the first column of a table and return a related value from another column.

2. What is a Pivot Table?

A Pivot Table is used to summarize, analyze and present large amounts of data quickly.

3. What is the difference between COUNT and COUNTA?

COUNT counts cells containing numbers, while COUNTA counts cells that are not empty.

SQL Interview Questions

4. What is SQL?

SQL stands for Structured Query Language. It is used to store, retrieve and manage data in relational databases.

5. What is the difference between WHERE and HAVING?

WHERE filters rows before grouping, while HAVING filters groups after GROUP BY.

6. What is a Primary Key?

A Primary Key uniquely identifies each record in a database table.

Database Interview Questions

1. What is a Database?

A database is an organized collection of data that can be stored, managed and retrieved efficiently.

2. What is DBMS?

DBMS stands for Database Management System. It is software used to create, store, manage and retrieve data from databases.

3. What is a Foreign Key?

A Foreign Key is used to create a relationship between two tables.

4. What is Normalization?

Normalization is the process of organizing data to reduce data duplication and improve consistency.

Power BI Interview Questions

7. What is Power BI?

Power BI is a business intelligence and data visualization tool used to analyze data and create interactive reports and dashboards.

8. What is a Dashboard?

A dashboard is a visual display of important information and key performance indicators.

Python Interview Questions

9. Why is Python used in Data Analytics?

Python is widely used for data analysis, data cleaning, visualization and automation.

10. What is Pandas?

Pandas is a Python library used for data manipulation and analysis.

Data Analyst Interview Questions

1. What does a Data Analyst do?

A Data Analyst collects, cleans, analyzes and interprets data to help businesses make better decisions.

2. What are the main skills required for a Data Analyst?

Important skills include Excel, SQL, Power BI, Python, data visualization, problem solving and communication.

3. What is Data Cleaning?

Data Cleaning is the process of identifying and correcting errors, missing values, duplicate records and inconsistent data.

4. What is Data Visualization?

Data Visualization means presenting data using charts, graphs and dashboards so that information is easier to understand.

5. What is the difference between Excel and SQL?

Excel is mainly used for spreadsheet-based analysis, while SQL is used to retrieve and manage data stored in databases.

Scenario-Based Interview Questions

1. What will you do if your dataset contains missing values?

I would first identify the missing values, understand why they are missing, and then decide whether to remove, replace or keep them based on the business requirement.

2. How would you handle duplicate records?

I would identify duplicate records and remove them if they represent repeated data, while making sure that valid repeated transactions are not incorrectly deleted.

3. What will you do if your manager gives you a large dataset?

I would first understand the business objective, inspect the data, clean it, analyze important metrics and then present the findings using clear visualizations.

4. What if your analysis shows an unexpected result?

I would verify the data, check the calculations and assumptions, investigate possible reasons and discuss the findings with the relevant team before presenting the conclusion.

5. How would you explain technical findings to a non-technical person?

I would use simple language, relevant examples and easy-to-understand charts instead of using complex technical terms.

HR & General Interview Questions

2. Why do you want to become a Data Analyst?

I enjoy working with data, finding patterns and solving business problems. Data Analytics allows me to use technical and analytical skills to support better business decisions.

3. What are your strengths?

My strengths are problem solving, decision making, learning quickly and adapting to new technologies.

4. What is your weakness?

I sometimes spend extra time making sure my work is accurate. I am improving this by setting priorities and managing my time effectively.

5. Why should we hire you as a fresher?

I have a strong interest in Data Analytics and I am continuously improving my technical skills. I am a quick learner, hardworking and ready to learn from real-world projects and experienced team members.
