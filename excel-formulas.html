🧮 Important Excel Formulas

Data Analyst Excel Formula Practice

1. SUM

Used to calculate the total of numbers.

=SUM(A1:A10)

2. AVERAGE

Used to calculate the average value.

=AVERAGE(A1:A10)

3. COUNT

Counts cells containing numbers.

=COUNT(A1:A10)

4. COUNTA

Counts cells that are not empty.

=COUNTA(A1:A10)

5. IF

Checks a condition and returns a result.

=IF(A1>=50,"Pass","Fail")

6. COUNTIF

Counts cells based on a condition.

=COUNTIF(A1:A10,">50")

7. SUMIF

Adds values based on a condition.

=SUMIF(A1:A10,">50",B1:B10)

8. VLOOKUP

Used to search for a value in a table.

=VLOOKUP(A2,D:E,2,FALSE)
