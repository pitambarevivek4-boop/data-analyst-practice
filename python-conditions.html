🔀 Python Conditions & Loops

Python Programming for Data Analysts

🔹 if Statement

The if statement executes code when a condition is true.

age = 25

if age >= 18:
    print("Adult")

🔹 if-else Statement

age = 16

if age >= 18:
    print("Adult")
else:
    print("Minor")

🔹 if-elif-else

Used when there are multiple conditions.

marks = 75

if marks >= 80:
    print("A")
elif marks >= 60:
    print("B")
else:
    print("C")

🔁 for Loop

A for loop is used to repeat code for each item in a sequence.

for i in range(1, 6):
    print(i)

🔄 while Loop

A while loop repeats code while a condition is true.

i = 1

while i <= 5:
    print(i)
    i += 1

🛑 break

break stops the loop immediately.

for i in range(1, 6):
    if i == 3:
        break
    print(i)

⏭️ continue

continue skips the current iteration and moves to the next one.

for i in range(1, 6):
    if i == 3:
        continue
    print(i)

🎯 Practice Question

Question: Which loop is commonly used to iterate through a sequence in Python?

Answer: for loop
