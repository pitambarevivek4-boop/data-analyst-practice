📘 Power BI Basics

Learn Power BI from Beginner Level

1. What is Power BI?

Power BI is a Microsoft business intelligence tool used to analyze data and create interactive reports and dashboards.

2. Power BI Desktop

Power BI Desktop is used to import data, clean data, create relationships, build visualizations and prepare reports.

3. Power BI Report

A report contains different visualizations such as charts, tables, cards and slicers.

4. Dashboard

A dashboard provides a visual summary of important business information and key metrics.

5. Data Sources

Power BI can connect to Excel, CSV, SQL Server, MySQL and many other data sources.

6. Visualizations

Common Power BI visuals include Bar Chart, Column Chart, Line Chart, Pie Chart, Table, Matrix and Card.

7. Filters

Filters help users display only the data they want to analyze.

8. Slicer

A slicer is an interactive visual filter that allows users to select values directly from a report.

📝 Practice Question

Which Microsoft tool is commonly used to create interactive data reports and dashboards?

✅ Answer: Power BI
