⌨️ Python Syntax & Variables

Python Programming for Data Analysts

📌 Python Syntax

Python syntax means the rules used to write Python code correctly.

print("Hello Data Analyst")

📦 Variables

Variables store information or values.

name = "Vivek"
age = 29
salary = 30000

🔢 Integer

Integer stores whole numbers.

age = 29
quantity = 100

🔢 Float

Float stores decimal numbers.

price = 199.50
percentage = 85.5

🔤 String

String stores text.

name = "Vivek"
city = "Mumbai"

✅ Boolean

Boolean has two values: True or False.

is_student = True
is_employee = False

🔍 type() Function

type() is used to check the data type of a value.

age = 29
print(type(age))

🔄 Changing Variable Value

A variable can be assigned a new value.

age = 29
age = 30
print(age)

🎯 Practice Question

Question: Which Python function is used to check the data type of a variable?

Answer: type()
