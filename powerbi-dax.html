🧮 Power BI DAX

Learn DAX Formulas for Data Analysis

1. What is DAX?

DAX stands for Data Analysis Expressions. It is the formula language used in Power BI for calculations and data analysis.

2. SUM()

SUM calculates the total of a numeric column.

Total Sales = SUM(Sales[Amount])

3. AVERAGE()

AVERAGE calculates the average value.

Average Sales = AVERAGE(Sales[Amount])

4. COUNT()

COUNT counts numeric values in a column.

Total Records = COUNT(Sales[Amount])

5. CALCULATE()

CALCULATE changes the filter context of a calculation.

Total Mumbai Sales = CALCULATE([Total Sales], Sales[City] = "Mumbai")

6. Measure

A measure is a DAX calculation that is evaluated dynamically based on the report context.

Total Sales = SUM(Sales[Amount])

7. Calculated Column

A calculated column creates a new column using a DAX formula.

Total = Sales[Quantity] * Sales[Price]

8. IF()

IF returns one value when a condition is true and another when it is false.

Status = IF(Sales[Amount] >= 10000, "High", "Low")

📝 Practice Question

Which DAX function is commonly used to modify filter context?

✅ Answer: CALCULATE()
